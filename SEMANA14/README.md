# TESTE DE USUÁRIO FINAL

## 1. Objetivo do Teste

Avaliar a facilidade de uso, eficiência e clareza da interface durante as etapas de **busca, comparação e simulação de compra** de um produto no site Mercado Livre.

Os alunos deverão **executar e observar o comportamento do usuário final**, aplicando conceitos de **IHC e testes de usabilidade**.

## 2. Cenário de Uso

Você está procurando **um fone de ouvido sem fio** para uso diário e quer comprar pelo Mercado Livre.

Seu objetivo é **encontrar um modelo com boa avaliação**, comparar opções e **simular a compra até o carrinho** (sem finalizar o pagamento).

## 3. Tarefas a Serem Executadas

1. Acessar o site [https://www.mercadolivre.com.br](https://www.mercadolivre.com.br).
2. Pesquisar **“fone de ouvido Bluetooth”**.
3. Usar os filtros para:
   - Selecionar apenas **produtos com entrega Full**;
   - Ordenar pelos **melhores avaliados**.
4. Escolher um produto e **acessar os detalhes**.
5. Adicionar o item ao carrinho.
6. Simular o início da compra (sem concluir o pagamento).
7. Retornar à tela inicial.

## 6. Dados Coletados

| Métrica | Descrição |
| --- | --- |
| **Tempo de execução** | Tempo total para completar todas as tarefas. |
| **Taxa de sucesso** | Quantos usuários conseguiram concluir o fluxo sem ajuda. |
| **Erros cometidos** | Cliques incorretos, perda do caminho, confusão nos filtros. |

## 7. Critérios de Sucesso

- 90% dos usuários devem conseguir adicionar o produto ao carrinho.
- Tempo médio para concluir o teste: **até 4 minutos**.

## 8. Recursos e Organização da Atividade

| Papel | Descrição |
| --- | --- |
| **Usuário final** | Aluno que executa as tarefas como comprador. |
| **Avaliador** | Colega que observa e registra tempo, erros e comentários. |
| **Instrutor** | Professor que orienta e supervisiona o teste. |

Ferramentas:

- Navegador web (Google Chrome, Firefox, Edge).
- Cronômetro ou celular para medir tempo.
- Planilha de observação (papel ou digital).
- Formulário SUS no Google Forms ou impresso.
