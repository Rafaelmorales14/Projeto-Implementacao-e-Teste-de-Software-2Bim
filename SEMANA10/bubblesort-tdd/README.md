# Bubble Sort com TDD

Ordenação de um vetor de inteiros em ordem crescente. O método `ordenar()` compara os elementos vizinhos e troca os que estão fora de ordem. Se uma passagem não fizer nenhuma troca, a ordenação termina.

Os três testes fornecidos foram preservados. Os testes adicionais verificam vetor vazio, um único elemento, números negativos e os limites de `int`.

Com JDK 17 ou superior e Maven instalados, execute nesta pasta:

```bash
mvn test
```

O vetor recebido pelo construtor é alterado diretamente. O enunciado está em [REQUISITOS.md](REQUISITOS.md).
